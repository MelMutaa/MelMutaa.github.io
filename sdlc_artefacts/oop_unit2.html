Exercise 1 — Line.__eq__ (order-insensitive)

Return True if two lines have equivalent endpoints in either order

This method compares two Line objects and returns True if they have the same endpoints, regardless of order.

def __eq__(self, other) -> bool:
    if not isinstance(other, Line):
        return NotImplemented
    # Check if endpoints match in either order
    return (self.p1 == other.p1 and self.p2 == other.p2) or \
           (self.p1 == other.p2 and self.p2 == other.p1)

Exercise 2 — Line.midpoint

Compute the midpoint of a line segment

This method calculates the midpoint between two points by averaging their x and y coordinates.

def midpoint(self) -> Point:
    """Return the midpoint of the line segment."""
    mid_x = (self.p1.x + self.p2.x) / 2
    mid_y = (self.p1.y + self.p2.y) / 2
    return Point(mid_x, mid_y)

Exercise 3 — Rectangle.midpoint

Find the center point of a rectangle

This method finds the center of a rectangle by averaging the x-coordinates and y-coordinates of the lower-left and upper-right points.

def midpoint(self) -> Point:
    """Return the center point of the rectangle."""
    center_x = (self.ll.x + self.ur.x) / 2
    center_y = (self.ll.y + self.ur.y) / 2
    return Point(center_x, center_y)

Exercise 4 — Rectangle.make_cross

Create cross lines through rectangle midpoints

This method creates a cross pattern inside the rectangle by connecting the midpoints of opposite sides.

def make_cross(self):
    """Return two lines connecting opposite midpoints forming a cross."""
    lines = self.make_lines()
    midpoints = [line.midpoint() for line in lines]
    # Connect opposite midpoints: bottom-top and left-right
    cross_line1 = Line(midpoints[0], midpoints[2])  # bottom to top
    cross_line2 = Line(midpoints[3], midpoints[1])  # left to right
    return [cross_line1, cross_line2]

Exercise 5 — Circle Class

Circle with center, radius, and drawing capability

This class represents a circle with a center point and radius, including string representation and drawing functionality.

class Circle:
    """Circle with center point and radius."""
    
    def __init__(self, center: Point, radius: float):
        self.center = center
        self.radius = radius
        
    def __str__(self) -> str:
        return f"Circle(center={self.center}, radius={self.radius})"
        
    def draw(self):
        """Draw the circle using jupyturtle functions."""
        import jupyturtle as jt
        jt.penup()
        jt.goto(self.center.x, self.center.y - self.radius)
        jt.pendown()
        jt.circle(self.radius)
