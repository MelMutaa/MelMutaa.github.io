Unit 11: Pointers, References, Memory, and Design Patterns

Welcome to Week 11. We explore Python’s reference model (no pointers), sustainability in code, and design patterns (creational, structural, behavioural).

Learning Overview

In this unit we shall:
  • Appreciate that Python does not use pointers (unlike C).
  • Understand how design choices affect software sustainability.
  • Recognise that code may be organised in various architectural styles.

On completion of this unit you will be able to:
  • Describe overhead of pointers in other languages and contrast with Python.
  • Discuss reasons Python can be more sustainable than others.
  • Experiment with design patterns to structure code.

Supports architectural thinking via design patterns and sustainable, maintainable design.
