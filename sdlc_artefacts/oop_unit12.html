Design Pattern Compatibility Analysis

Evaluating Pattern Combinations for Complex Systems

Design Pattern Compatibility Assessment

Which design patterns do you consider to be compatible with others, and why?

Pattern Compatibility Framework

Design patterns can be effectively combined when they address different concerns in a system architecture. Compatibility is determined by:

  • Separation of Concerns: Patterns should handle distinct responsibilities
  • Architectural Layer Alignment: Patterns operating at different layers can complement each other
  • Complexity Management: Combined patterns should reduce, not increase, system complexity
  • Maintainability: Pattern combinations should enhance code organization and readability

Highly Compatible Pattern Combinations

1. MVC + Strategy + Observer

Compatibility: Excellent

Rationale: MVC provides architectural separation, Strategy handles algorithm variation, Observer manages view updates.

Use Case: Cruise ship booking system with multiple payment strategies and real-time availability updates.

2. Factory + Singleton + Decorator

Compatibility: High

Rationale: Factory creates objects, Singleton ensures single instances where needed, Decorator adds functionality dynamically.

Use Case: Service management system with single service registry and dynamic service enhancements.

3. Command + Memento + Composite

Compatibility: High

Rationale: Command encapsulates actions, Memento enables undo/redo, Composite handles hierarchical command structures.

Use Case: Complex itinerary planning with undo capabilities and grouped operations.

Pattern Compatibility Matrix

Decorator Composite High Flexible component hierarchies with dynamic enhancements Complex object relationships

class CruiseShipPatternCombinations:
    """
    Demonstrates effective design pattern combinations for cruise management.
    """
    
    # Strategy + Factory Pattern Combination
    class PricingStrategyFactory:
        """Factory creating different pricing strategies."""
        
        @staticmethod
        def create_strategy(season, cabin_type):
            if season == "PEAK":
                return PeakSeasonStrategy()
            elif cabin_type == "SUITE":
                return SuitePricingStrategy()
            else:
                return StandardPricingStrategy()
    
    class PricingStrategy(ABC):
        """Strategy pattern for different pricing algorithms."""
        
        @abstractmethod
        def calculate_price(self, base_price, duration):
            pass
    
    # Observer + Singleton Pattern Combination  
    class AvailabilityManager(metaclass=Singleton):
        """Singleton managing cabin availability with observer notifications."""
        
        def __init__(self):
            self._observers = []
            self._available_cabins = {}
        
        def add_observer(self, observer):
            self._observers.append(observer)
        
        def update_availability(self, cabin_id, available):
            self._available_cabins[cabin_id] = available
            self._notify_observers(cabin_id, available)
        
        def _notify_observers(self, cabin_id, available):
            for observer in self._observers:
                observer.on_availability_change(cabin_id, available)
    
    # Command + Memento Pattern Combination
    class BookingCommand(ABC):
        """Command pattern for booking operations."""
        
        @abstractmethod
        def execute(self):
            pass
        
        @abstractmethod
        def undo(self):
            pass
    
    class BookingMemento:
        """Memento pattern for booking state preservation."""
        
        def __init__(self, state):
            self._state = state
        
        def get_state(self):
            return self._state
    
    class BookCabinCommand(BookingCommand):
        """Concrete command for cabin booking with undo capability."""
        
        def __init__(self, booking_system, passenger, cabin):
            self.booking_system = booking_system
            self.passenger = passenger
            self.cabin = cabin
            self._memento = None
        
        def execute(self):
            # Save state before execution for undo
            self._memento = self.booking_system.create_memento()
            return self.booking_system.book_cabin(self.passenger, self.cabin)
        
        def undo(self):
            if self._memento:
                self.booking_system.restore_from_memento(self._memento)

Incompatible Pattern Combinations

Patterns with Potential Conflicts

  • Singleton + Prototype: Singleton's single instance conflicts with Prototype's cloning mechanism
  • Observer + Mediator: Both handle communication but at different abstraction levels, can create confusion
  • Factory Method + Abstract Factory: Overlapping responsibilities in object creation can lead to complexity

# Singleton + Factory Pattern Combination
class ServiceRegistry:
    """
    Singleton service registry managing all cruise services.
    Combines Singleton with Factory for service management.
    """
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._services = {}
        return cls._instance
    
    def register_service(self, service_name, service_factory):
        """Register a service factory."""
        self._services[service_name] = service_factory
    
    def get_service(self, service_name, *args, **kwargs):
        """Get service instance using factory pattern."""
        factory = self._services.get(service_name)
        if factory:
            return factory(*args, **kwargs)
        raise ValueError(f"Service {service_name} not registered")


# Strategy + Factory Pattern Combination
class PricingStrategy(ABC):
    """Strategy pattern for different pricing algorithms."""
    
    @abstractmethod
    def calculate_price(self, base_price: float, duration: int, passengers: int) -> float:
        pass


class PeakSeasonStrategy(PricingStrategy):
    def calculate_price(self, base_price: float, duration: int, passengers: int) -> float:
        return base_price * duration * passengers * 1.5  # 50% premium


class OffPeakStrategy(PricingStrategy):
    def calculate_price(self, base_price: float, duration: int, passengers: int) -> float:
        return base_price * duration * passengers * 0.8  # 20% discount


class PricingStrategyFactory:
    """Factory for creating pricing strategies."""
    
    @staticmethod
    def create_strategy(season: str, cabin_type: str) -> PricingStrategy:
        if season == "PEAK":
            return PeakSeasonStrategy()
        elif cabin_type == "LUXURY":
            return PeakSeasonStrategy()  # Luxury always premium
        else:
            return OffPeakStrategy()


# Observer + Decorator Pattern Combination
class AvailabilityObserver(ABC):
    """Observer interface for availability changes."""
    
    @abstractmethod
    def on_availability_change(self, cabin_id: str, available: bool):
        pass


class EmailNotificationDecorator(AvailabilityObserver):
    """Decorator adding email notifications to observers."""
    
    def __init__(self, wrapped_observer: AvailabilityObserver):
        self._wrapped_observer = wrapped_observer
    
    def on_availability_change(self, cabin_id: str, available: bool):
        # Add email notification functionality
        if available:
            self._send_availability_email(cabin_id)
        self._wrapped_observer.on_availability_change(cabin_id, available)
    
    def _send_availability_email(self, cabin_id: str):
        print(f"Email sent: Cabin {cabin_id} is now available!")


class CabinAvailabilityManager:
    """Manages cabin availability with observer pattern."""
    
    def __init__(self):
        self._observers: List[AvailabilityObserver] = []
        self._availability: Dict[str, bool] = {}
    
    def add_observer(self, observer: AvailabilityObserver):
        """Add observer with optional decorator."""
        self._observers.append(observer)
    
    def set_availability(self, cabin_id: str, available: bool):
        """Set availability and notify observers."""
        self._availability[cabin_id] = available
        self._notify_observers(cabin_id, available)
    
    def _notify_observers(self, cabin_id: str, available: bool):
        for observer in self._observers:
            observer.on_availability_change(cabin_id, available)


# Command + Memento Pattern Combination
class BookingCommand(ABC):
    """Command interface for booking operations."""
    
    @abstractmethod
    def execute(self) -> bool:
        pass
    
    @abstractmethod
    def undo(self):
        pass


class BookingMemento:
    """Memento for storing booking system state."""
    
    def __init__(self, state: dict):
        self._state = state.copy()
    
    def get_state(self) -> dict:
        return self._state


class BookCabinCommand(BookingCommand):
    """Concrete command for booking a cabin."""
    
    def __init__(self, booking_system, passenger_id: str, cabin_id: str, duration: int):
        self.booking_system = booking_system
        self.passenger_id = passenger_id
        self.cabin_id = cabin_id
        self.duration = duration
        self._memento: BookingMemento = None
    
    def execute(self) -> bool:
        # Save state before execution
        self._memento = self.booking_system.create_memento()
        return self.booking_system.book_cabin(
            self.passenger_id, self.cabin_id, self.duration
        )
    
    def undo(self):
        if self._memento:
            self.booking_system.restore_from_memento(self._memento)


class CancelBookingCommand(BookingCommand):
    """Concrete command for canceling a booking."""
    
    def __init__(self, booking_system, booking_id: str):
        self.booking_system = booking_system
        self.booking_id = booking_id
        self._memento: BookingMemento = None
        self._cancelled_booking = None
    
    def execute(self) -> bool:
        self._memento = self.booking_system.create_memento()
        self._cancelled_booking = self.booking_system.cancel_booking(self.booking_id)
        return self._cancelled_booking is not None
    
    def undo(self):
        if self._memento and self._cancelled_booking:
            self.booking_system.restore_from_memento(self._memento)
            # Re-book the cancelled booking
            self.booking_system.book_cabin(
                self._cancelled_booking.passenger_id,
                self._cancelled_booking.cabin_id,
                self._cancelled_booking.duration
            )


# Composite + Visitor Pattern Combination
class ServiceComponent(ABC):
    """Component interface for service hierarchy."""
    
    @abstractmethod
    def accept(self, visitor: 'ServiceVisitor'):
        pass
    
    @abstractmethod
    def get_cost(self) -> float:
        pass


class IndividualService(ServiceComponent):
    """Leaf node representing individual service."""
    
    def __init__(self, name: str, cost: float):
        self.name = name
        self.cost = cost
    
    def accept(self, visitor: 'ServiceVisitor'):
        visitor.visit_individual_service(self)
    
    def get_cost(self) -> float:
        return self.cost


class ServicePackage(ServiceComponent):
    """Composite node representing service package."""
    
    def __init__(self, name: str):
        self.name = name
        self.services: List[ServiceComponent] = []
    
    def add_service(self, service: ServiceComponent):
        self.services.append(service)
    
    def accept(self, visitor: 'ServiceVisitor'):
        visitor.visit_service_package(self)
        for service in self.services:
            service.accept(visitor)
    
    def get_cost(self) -> float:
        return sum(service.get_cost() for service in self.services) * 0.9  # 10% discount


class ServiceVisitor(ABC):
    """Visitor for performing operations on service hierarchy."""
    
    @abstractmethod
    def visit_individual_service(self, service: IndividualService):
        pass
    
    @abstractmethod
    def visit_service_package(self, package: ServicePackage):
        pass


class CostCalculationVisitor(ServiceVisitor):
    """Visitor for calculating total costs."""
    
    def __init__(self):
        self.total_cost = 0.0
    
    def visit_individual_service(self, service: IndividualService):
        self.total_cost += service.get_cost()
    
    def visit_service_package(self, package: ServicePackage):
        # Package discount already applied in get_cost()
        self.total_cost += package.get_cost()


# Main Cruise Management System
class CruiseManagementSystem:
    """
    Main system integrating all pattern combinations.
    Demonstrates how compatible patterns work together.
    """
    
    def __init__(self):
        self.service_registry = ServiceRegistry()
        self.availability_manager = CabinAvailabilityManager()
        self._bookings = {}
        self._booking_history = []
        
        # Register services
        self.service_registry.register_service('pricing', PricingStrategyFactory())
    
    def book_cabin(self, passenger_id: str, cabin_id: str, duration: int) -> bool:
        """Book a cabin using command pattern."""
        command = BookCabinCommand(self, passenger_id, cabin_id, duration)
        success = command.execute()
        if success:
            self._booking_history.append(command)
        return success
    
    def create_memento(self) -> BookingMemento:
        """Create memento of current state."""
        return BookingMemento({
            'bookings': self._bookings.copy(),
            'availability': self.availability_manager._availability.copy()
        })
    
    def restore_from_memento(self, memento: BookingMemento):
        """Restore system state from memento."""
        state = memento.get_state()
        self._bookings = state['bookings'].copy()
        self.availability_manager._availability = state['availability'].copy()
